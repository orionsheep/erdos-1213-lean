# Earlier contributions

This is an additional implementation of JSP-001018 / Erdős Problem 1213. It does not claim the first Lean proof, a new mathematical solution or established award priority.

The mathematical result is due to **Norbert Hegyvári**, *On consecutive sums in sequences*, Acta Mathematica Hungarica 48 (1986), 193–200, Section 3, Theorem 3, pp.197–198, [DOI 10.1007/BF01949064](https://doi.org/10.1007/BF01949064). Original solver credit is distinct from preparing a later Lean implementation.
